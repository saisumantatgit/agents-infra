## R14-02 — ERROR-B, CRITICAL, **NEW**. An unlisted multiplier switches the spelled-figure guard down to the bare scale word

**Mechanism.** `_spelled_quantity_phrases` builds **maximal runs of words that
are members of `_SPELLED_NUMBER_WORDS`** and breaks the run at any non-member.
`one` is deliberately excluded (a recorded CEILING), and `several`, `a few`,
`many`, `numerous` were never candidates. So the multiplier breaks the run and
the extracted phrase is the *scale word alone*:

```python
_spelled_quantity_phrases("one million")        -> ('million',)
_spelled_quantity_phrases("several thousand …") -> ('thousand',)
_spelled_quantity_phrases("a few hundred")      -> ('hundred',)
_spelled_quantity_phrases("many thousands")     -> ('thousands',)
_spelled_quantity_phrases("numerous millions")  -> ('millions',)
```

`spelled_quantity_ok` then asks only whether the word `million` occurs
somewhere in a cited source — which any source stating *any* millions-scale
figure satisfies. **The magnitude is unchecked.**

This contradicts the guarantee written into the code at
`ground_check.py` (`_SPELLED_NUMBER_WORDS` docstring block):
*"A spelled figure of one that carries a scale word is still checked, because
the scale word is in the set (`"one million"` → the phrase `"one million"` is
checked via `"million"`)."* The phrase checked is `"million"`, not
`"one million"`, and checking `"million"` constrains nothing about the figure.

## R14-03 — ERROR-B, CRITICAL, **NEW**. The ABSENCE branch checks only what follows its trigger; everything before it is unchecked by anything

**Mechanism, two parts.**

1. **Branch order.** In `ground()`, `if claim.kind == ClaimKind.ABSENCE: …
   return check_absence(...)` sits **above** the two figure checks that D-77
   made kind-independent. An `ABSENCE` claim therefore never reaches
   `numeric_ok` or `spelled_quantity_ok`. `classify`'s cascade is
   `NON_CLAIM → RELATIONAL → ABSENCE → NUMERIC`, so any sentence containing
   `no ` / `not ` is `ABSENCE` whatever figures it carries.
2. **Anchor scope.** `_extract_absence_anchors` does
   `remainder = text[match.end():]` on `_ABSENCE_LEAD_RE` — so the strong-anchor
   rule (named entities + any token containing a digit) reads **only the text
   after the negation trigger**. Word order is the author's. Everything before
   the trigger is outside both the anchor rule and the figure checks, i.e.
   checked by nothing at all.

**Score dilution past the ADR-005 appendix rule.** 20 genuinely grounded claims
+ 1 fabrication (`MongoDB destroys every write on restart [S1].`) →
`gate=NEEDS_WORK`, `grounding_score=95.2`, `retained_appendix` length 1,
exit 1. A ratio cannot buy a PASS past a retained violation; the rule holds.

**Prefixing a fabrication to an absence across a conjunction.** `… and this is
not recorded in the maintenance log.` / `…, which is not recorded in …` — the
conjunction splitter separates the prefix into its own claim, which then reads
`UNCITED` and caps the gate (`gate=FAIL`, score 50.0, exit 1). R14-03 therefore
holds only inside a **single clause**, which is how it is reported.

**Draft-side contracted negation on the verbatim path.** `… desk didn't identify
material weaknesses [S1].` against `… desk did identify material weaknesses in
three accounts.` → `UNGROUNDED`, FAIL, exit 1; the curly-apostrophe variant
`didn’t` likewise. (`_reconstruct_sentence` renders the contraction as one
token, which fails coverage — fail-closed here, and a pre-existing fidelity
defect noted in the code's own comments, not a new finding.)

**Explicit `not ` / `no ` negation in a FACTUAL draft.** Routed to `ABSENCE` by
`classify`, then refused by `check_absence` (`UNVERIFIED_ABSENCE`, FAIL, exit 1)
because the store's queries did not address the subject. The stop-word status of
`not`/`no` is not exploitable on the verbatim path for the *draft's* negation,
only for the *source's* (R14-04).

**A fabricated `[S9]` under every routing I tried**, including inside the
blockquote and inside an absence sentence — `UNVERIFIED_CITATION`, gate capped,
exit 1 every time. J-25's provenance-before-kind check holds; it is the one
rule in the grounding path this round could not move.

**Fractional and vague quantifiers through the verbatim path** (`a third`,
`a fifth`, `half`, `double`, `twice`, `scores of`, `a handful of`, Roman
numerals `XCVII`/`MMXIX`, `umpteen`, `myriad`): all produce **no** phrase from
either figure check — but all are refused in practice, because the fraction
word itself is a content word that set-membership coverage then requires in the
source. The documented ordinal/vague-quantifier ceiling is real but, on the
verbatim path, is masked by coverage. It is **not** masked on the `ABSENCE`
path, where coverage does not run — that is R14-03.

**Full-width and superscript digits.** `１２８０００` NFKC-folds to `128000`
and is caught by `_NUMERIC_RE`; `2³` folds to the token `23`, a mutation whose
only exploit requires the source to state `23`, which is a strictly contrived
store. Neither produced a PASS on a figure the source lacked.
