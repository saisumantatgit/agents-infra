## R26-01 — Same-sentence check bypassed by newline, semicolon, parenthesis | HIGH
Mechanism: `_split_sentences` splits only on `[.!?]` followed by whitespace. A newline-separated list/table row, `;`, or `(...)` makes two facts one "sentence", so the borrowed word counts as covered (W2A-01 entity swap returns).
Reproduction (claim "SUBJ was migrated to Spanner in June [S1]."):
- source "SUBJ was migrated to Aurora in March\nThe MySQL fleet was migrated to Spanner in June" -> HEAD PASS/GROUNDED, base PASS/GROUNDED
- "...Aurora in March; the MySQL fleet was migrated to Spanner in June." -> HEAD PASS, base PASS
- "...Aurora in March (the MySQL fleet was migrated to Spanner in June)." -> HEAD PASS, base PASS
Which: evasion of fix 2 (pre-existing hole, not narrowed by it). Newline case is the most realistic: web pages, Read files, lists and tables without periods.
Sibling: CEILING comment names within-sentence reversal only; it does not name unpunctuated lines.

## R26-02 — Qualifier detached by space / NBSP / zero-width char | HIGH
Mechanism: `_figure_qualifiers` walks back from the digit and stops at any char outside {., Sm, Sc, Pd}; a space, U+00A0 or U+200B ends the run with zero qualifiers.
Reproduction (claim "... 12% in 2023 according to the annual report [S1]."):
- source "- 12%" -> HEAD PASS/GROUNDED; "- 12%" -> PASS; "-​12%" -> PASS
- "± 3%" vs claim "3%" -> PASS; "~ 40%" vs "40%" -> PASS; ". 5%" vs "5%" -> PASS
All PASS on base too. Unicode minus U+2212, full-width U+FF0D and trailing ¥ now refuse (fix works for attached glyphs).
Which: evasion of fix 4. Upgrade: skip Zs/Cf between the qualifier run and the digit (fail-closed direction).

## R26-03 — Accounting-negative "(12%)" grounds "12%" | MEDIUM

A Read of an earlier version / notes file that differs by one word, or a separate file the agent wrote holding just the claim sentence and read WHOLE (extent "whole" exempts it from containment), still grounds the draft.
