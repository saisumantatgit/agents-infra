## R28-01 — A flat denial in the previous sentence no longer blocks grounding | CRITICAL
Mechanism: `_span_is_hedged_in_source` drops not/no/never when they sit in the previous sentence, unless that sentence holds a word from the 16-word `_TRUTH_PREDICATES` list. A denial is not obliged to use one of those words: "happened", "occurred", "event", "supported", "endorse", or no verb at all.
Reproduction (NEW / BASE):
- "This is not what happened." PASS / FAIL
- "No such event occurred." PASS / FAIL
- "This never happened." PASS / FAIL
- "No." PASS / FAIL
- "Not!" PASS / FAIL
- "Not at all." PASS / FAIL
- "It did not happen. Never." PASS / FAIL
- "Did this not happen?" PASS / FAIL (negated question)
- "The rumour is not supported by any evidence." PASS / FAIL
- "Nothing like this ever happened, not once." PASS / FAIL
- "Here is a rumour we do not endorse." PASS / FAIL
- "Never... " (an ellipsis read as a sentence boundary) PASS / FAIL
REGRESSION (C2). Sibling: every unlisted predicate of falsity or non-occurrence. The truth-predicate list puts the attacker on the side that enumerates, the D-69 class.

## R28-02 — An abbreviation's full stop is read as a sentence boundary | HIGH
Mechanism: `_SENTENCE_BOUNDARY_RE` treats "Jan. " and "U.S. " followed by a capital as the end of a sentence, so a span that starts mid-sentence is treated as starting a new one.
Reproduction: "Not in Jan. {claim}" gives NEW PASS / BASE FAIL. "No, not in the U.S. {claim}" gives NEW PASS / BASE FAIL.
REGRESSION (C2). Sibling: Dr., e.g., p.m. and decimal-like tokens; any proper-noun claim after an abbreviation.
