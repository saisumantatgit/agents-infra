# API reference: webhooks

1. A page holds at most 34 items [S1].
2. Timestamps use the UTC time zone [S1].
3. The `status` parameter is optional [S1].
4. Version 1.1 of the API is the current release [S1].
5. The rate limit is 5417 requests per minute for each key [S1].
6. Every error body is made up of a code, a message and a request id [S1].
