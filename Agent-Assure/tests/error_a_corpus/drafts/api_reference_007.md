## Error codes

1. Use the `cursor` value from one page to request the next [S1].
2. A page holds at most 22 items [S1].
3. Requests with a body must set a content type [S1].
4. The server retries failed webhooks [S1].
5. Every error body is made up of a code, a message and a request id [S1].
6. The changelog says that the old `v1` path "is not covered by the new limits" [S1].
7. The beta `status` filter never left preview and is not documented here [S1].
8. Version 4.6 of the API is the current release [S1].
9. The shipments endpoint returns JSON [S1].
10. The `status` parameter is optional [S1].
