## Prerequisites

- The command prints one line for each file it handles [S1].
- This guide assumes `tar` is already installed [S1].
- Each step below can be repeated safely [S1].
- Version 6.5 or later is required [S1].
- Large folders of more than 9347 files may take several minutes [S1].
- The older `--legacy` mode never supported symbolic links [S1].
