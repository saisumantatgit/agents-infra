# How to copy a key with rsync

- The command prints one line for each file it handles [S1].
- Each step below can be repeated safely [S1].
- Run the command from the notes folder [S1].
- It will not work from a folder without write access [S1].
- The tool prints a summary when it finishes [S1].
- The manual warns that the option "cannot be undone" [S1].
- Version 1.6 or later is required [S1].
- The default timeout is 47 seconds [S1].
- The older `--legacy` mode never supported symbolic links [S1].
- Keep a copy of the notes until you have checked the result [S1].
- Open a terminal in the folder that holds your notes [S1].
