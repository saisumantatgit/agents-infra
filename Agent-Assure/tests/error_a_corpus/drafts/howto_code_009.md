# How to move a branch with tar

1. The whole procedure takes about 27 minutes [S1].
2. Open a terminal in the folder that holds your notes [S1].
3. Use `sudo` only when the target is a system folder [S1].
4. The `--dry-run` flag shows the plan [S1].
5. It does not change any files [S1].
6. The archive is made up of the notes folder and a small manifest file [S1].
7. The manual warns that the option "cannot be undone" [S1].
8. Version 5.1 or later is required [S1].
9. Check the exit status with `echo $?` after the command ends [S1].
10. This guide assumes `tar` is already installed [S1].
