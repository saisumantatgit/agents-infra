# How to copy a key with ssh

- This guide assumes `ssh` is already installed [S1].
- Each step below can be repeated safely [S1].
- The command prints one line for each file it handles [S1].
- The older `--legacy` mode never supported symbolic links [S1].
- Large folders of more than 8672 files may take several minutes [S1].
- The default timeout is 18 seconds [S1].
