## Common errors

- Keep a copy of the photos until you have checked the result [S1].
- Open a terminal in the folder that holds your photos [S1].
- The `--dry-run` flag shows the plan [S1].
- Existing files are kept [S1].
- The older `--legacy` mode never supported symbolic links [S1].
- Large folders of more than 7775 files may take several minutes [S1].
- The default timeout is 34 seconds [S1].
- The archive is made up of the photos folder and a small manifest file [S1].
- Check the exit status with `echo $?` after the command ends [S1].
- Run the command once to see what it would do [S1].
