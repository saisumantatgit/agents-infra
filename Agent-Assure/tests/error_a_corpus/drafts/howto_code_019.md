## Useful flags

This guide assumes `ssh` is already installed [S1]. The whole procedure takes about 26 minutes [S1]. Run the command from the reports folder [S1]. Use `sudo` only when the target is a system folder [S1].

The default timeout is 26 seconds [S1]. The archive is made up of the reports folder and a small manifest file [S1]. Version 5.3 or later is required [S1]. The command prints one line for each file it handles [S1].

Open a terminal in the folder that holds your reports [S1].
