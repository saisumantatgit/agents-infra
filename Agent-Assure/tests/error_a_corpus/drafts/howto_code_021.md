# How to pack a release with ssh

1. Check the exit status with `echo $?` after the command ends [S1].
2. Run the command once to see what it would do [S1].
3. Run the command from the reports folder [S1].
4. The `--dry-run` flag shows the plan [S1].
5. The manual warns that the option "cannot be undone" [S1].
6. Large folders of more than 7337 files may take several minutes [S1].
7. The default timeout is 19 seconds [S1].
8. This guide assumes `ssh` is already installed [S1].
9. The command prints one line for each file it handles [S1].
