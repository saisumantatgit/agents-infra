## Release notes

Owners can rename a folder from the settings page [S1]. Changes made on one device appear on the others within a few seconds [S1]. Fenwick Notes syncs exports in the background [S1]. The Business plan includes scheduled exports [S1].

The Starter plan does not include scheduled exports [S1]. The Business plan costs 30 dollars per member each month [S1]. Each folder is made up of folders, pages and a shared activity log [S1]. The release notes say the change "does not affect existing exports" [S1].

The planned redesign of the folder list never shipped in the 2025 cycle [S1]. Uploads larger than 8351 MB are rejected [S1]. Each folder keeps its exports for 30 days after a member removes them [S1]. A folder can hold up to 8351 exports [S1].
