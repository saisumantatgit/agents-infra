## Plan limits

- Changes made on one device appear on the others within a few seconds [S1].
- A workspace can hold up to 6406 attachments [S1].
- The Starter plan does not include offline mode [S1].
- The Team plan includes offline mode [S1].
- Exports download as a single archive [S1].
- The archive is created without the original file permissions [S1].
- Version 9.8 added offline mode to every plan [S1].
- Uploads larger than 6406 MB are rejected [S1].
- Each workspace is made up of folders, pages and a shared activity log [S1].
- The Team plan includes offline mode for up to 12 members [S1].
- Search covers titles, tags and the first 12 lines of every note [S1].
