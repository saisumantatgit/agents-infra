## Plan limits

A folder can hold up to 630 drafts [S1]. Tidepool stores every folder in the account that created it [S1]. The Studio plan includes offline mode [S1]. Exports download as a single archive [S1].

The Starter plan does not include offline mode [S1]. Uploads larger than 630 MB are rejected [S1]. Support told the Studio customers that the delay "was not caused by the new release" [S1]. The planned redesign of the folder list never shipped in the 2026 cycle [S1].

Each folder is made up of folders, pages and a shared activity log [S1]. Changes made on one device appear on the others within a few seconds [S1]. Members open offline mode from the toolbar above the folder list [S1].
