# Pinecone Queue: working with offline mode

Pinecone Queue stores every project in the account that created it [S1]. Owners can rename a project from the settings page [S1]. An owner may invite 5 guests per project [S1]. Guests can view a shared project [S1].

The offline mode beta never left the Starter plan [S1]. A weekly summary is made up of the 5 busiest projects and a list of overdue items [S1]. The release notes say the change "does not affect existing attachments" [S1]. Version 5.6 added offline mode to every plan [S1].

The Starter plan includes offline mode for up to 5 members [S1]. A project can hold up to 2419 attachments [S1].
