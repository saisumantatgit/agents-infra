# Fenwick Notes: working with offline mode

1. Fenwick Notes stores every folder in the account that created it [S1].
2. Search covers titles, tags and the first 23 lines of every note [S1].
3. Fenwick Notes syncs comments in the background [S1].
4. Sync pauses unless the device is connected to a network [S1].
5. The Studio plan includes offline mode [S1].
6. Each folder is made up of folders, pages and a shared activity log [S1].
7. The Studio plan costs 23 dollars per member each month [S1].
8. The offline mode beta never left the Studio plan [S1].
9. Uploads larger than 7532 MB are rejected [S1].
10. A folder can hold up to 7532 comments [S1].
11. The Studio plan includes offline mode for up to 23 members [S1].
