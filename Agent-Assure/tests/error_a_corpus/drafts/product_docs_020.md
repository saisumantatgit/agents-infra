# Marlin Sync: working with shared workspaces

- Marlin Sync stores every folder in the account that created it [S1].
- Marlin Sync sends a summary email to the owner every Monday morning [S1].
- The Team plan includes shared workspaces for up to 38 members [S1].
- The Team plan costs 38 dollars per member each month [S1].
