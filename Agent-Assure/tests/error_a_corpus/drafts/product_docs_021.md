## Storage limits

Brightwell sends a summary email to the owner every Monday morning [S1]. Brightwell stores every project in the account that created it [S1]. Guests can view a shared project [S1]. Brightwell syncs drafts in the background [S1].

The Studio plan costs 39 dollars per member each month [S1]. The free trial lasts 39 days and needs no card [S1]. Each project is made up of folders, pages and a shared activity log [S1]. A project can hold up to 2511 drafts [S1].

The Studio plan includes offline mode for up to 39 members [S1].
