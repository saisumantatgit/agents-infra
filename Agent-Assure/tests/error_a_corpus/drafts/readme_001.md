## Breaking changes

- The test suite runs in under 16 seconds on a laptop [S1].
- Bug reports should include the version printed by `driftq --version` [S1].
- The `follow_links` option defaults to off [S1].
- The command exits with status 0 on success [S1].
- It exits without printing anything when the input is empty [S1].
- The project supports Python versions from the last 6 releases [S1].
- The default batch size is 5594 messages [S1].
- The package is made up of a reader, a writer and a small command line tool [S1].
- The planned Windows installer never reached a stable release [S1].
- The `follow_links` option is read from the config file at startup [S1].
- Install it with the package manager that ships with Python [S1].
