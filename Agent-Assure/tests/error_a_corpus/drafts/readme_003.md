# Pebblecache

- The library has no runtime dependencies beyond the Python standard library [S1].
- The test suite runs in under 9 seconds on a laptop [S1].
- The parser does not accept comments inside values [S1].
- The parser accepts trailing commas [S1].
- The command exits with status 0 on success [S1].
- The maintainers wrote that the old API "cannot be removed before version 2" [S1].
- The planned Windows installer never reached a stable release [S1].
- Version 7.1 reduced memory use by 82 percent on large inputs [S1].
- The package is made up of a reader, a writer and a small command line tool [S1].
- Contributions are welcome through pull requests [S1].
- Bug reports should include the version printed by `pebblecache --version` [S1].
