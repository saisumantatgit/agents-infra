## Install notes

Wickerdb is a small TypeScript library for reading and writing records [S1]. Contributions are welcome through pull requests [S1]. The test suite runs in under 18 seconds on a laptop [S1]. The default batch size is 6925 records [S1].

Each batch is made up of at most 6925 records [S1]. Version 8.3 reduced memory use by 92 percent on large inputs [S1].
