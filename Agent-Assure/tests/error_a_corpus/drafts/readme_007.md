## Planned features

- The library has no runtime dependencies beyond the TypeScript standard library [S1].
- Contributions are welcome through pull requests [S1].
- It exits without printing anything when the input is empty [S1].
- The command exits with status 0 on success [S1].
- The `verbose` option defaults to off [S1].
- Each batch is made up of at most 712 rows [S1].
- The project supports TypeScript versions from the last 8 releases [S1].
- The planned Windows installer never reached a stable release [S1].
- The default batch size is 712 rows [S1].
- The maintainers wrote that the old API "cannot be removed before version 2" [S1].
- Bug reports should include the version printed by `tallyman --version` [S1].
- The `verbose` option is read from the config file at startup [S1].
