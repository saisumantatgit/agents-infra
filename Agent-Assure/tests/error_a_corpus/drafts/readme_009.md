## Known limits

- Foldkit is a small TypeScript library for reading and writing events [S1].
- Contributions are welcome through pull requests [S1].
- Files are opened in binary mode [S1].
- The `verbose` option defaults to off [S1].
- The planned Windows installer never reached a stable release [S1].
- Each batch is made up of at most 3912 events [S1].
- The project supports TypeScript versions from the last 5 releases [S1].
- The default batch size is 3912 events [S1].
- Install it with the package manager that ships with TypeScript [S1].
- Every public function is documented in the docs folder [S1].
