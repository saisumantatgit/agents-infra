# Pebblecache

The `verbose` option is read from the config file at startup [S1]. Every public function is documented in the docs folder [S1]. Reads are buffered [S1]. The parser accepts trailing commas [S1].

Version 4.1 reduced memory use by 17 percent on large inputs [S1]. Each batch is made up of at most 1078 records [S1]. The maintainers wrote that the old API "cannot be removed before version 2" [S1]. The planned Windows installer never reached a stable release [S1].

The project supports Go versions from the last 5 releases [S1]. Install it with the package manager that ships with Go [S1]. Pebblecache is a small Go library for reading and writing records [S1].
