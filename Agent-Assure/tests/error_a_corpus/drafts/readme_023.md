## Planned features

The library has no runtime dependencies beyond the Rust standard library [S1]. Driftq is a small Rust library for reading and writing rows [S1]. Install it with the package manager that ships with Rust [S1]. Version 2.8 reduced memory use by 84% on large inputs [S1].

The maintainers wrote that the old API "cannot be removed before version 2" [S1].
