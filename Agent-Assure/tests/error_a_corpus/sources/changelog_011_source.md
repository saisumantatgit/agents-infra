# Fieldnote changelog, version 8.7

The installer now checks for free disk space first. Improved the wording of 5 error messages. Fixed a crash that happened when a name contained an emoji.

The documentation site was rebuilt for this release. Translations were refreshed by volunteers. The release was tagged after the final review.

This release is made up of 5 new features and 6 fixes. Support for the 8.7 series ends in 2019. The download is 9415 KB smaller than the previous release.

Documentation for the importer has been rewritten. Updated the bundled certificates. Added a new importer that loads in under a second. The importer now shows the time of the last change.

Contributors are listed in the credits file. Binary packages are built for three platforms. Checksums are published beside each download.
