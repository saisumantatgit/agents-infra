# Lumen CLI changelog, version 7.6

Startup is about 45% faster on cold caches. Improved the wording of 3 error messages. Fixed a crash that happened when a name contained an emoji.

A migration guide covers the larger changes. Checksums are published beside each download. Translations were refreshed by volunteers.

The deprecated `auto_retry` option never worked on the command line. Support for the 7.6 series ends in 2024. The download is 4568 KB smaller than the previous release.

The exporter now shows the time of the last change. The installer now checks for free disk space first. Added a new exporter that loads in under a second. Updated the bundled certificates.

Contributors are listed in the credits file. The next release is planned for the end of the quarter. Nightly builds continue on the usual schedule.
