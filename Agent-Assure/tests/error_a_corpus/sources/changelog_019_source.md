# Lumen CLI changelog, version 6.8

Added a new settings screen that loads in under a second. Documentation for the settings screen has been rewritten. The settings screen now shows the time of the last change.

Translations were refreshed by volunteers. The release was tagged after the final review. Thanks to everyone who reported problems this cycle.

It can still be turned off in the configuration file. The `compact_view` setting is now on by default. Upgrading does not delete existing data. Support for version 6 has been removed.

This release is made up of 6 new features and 27 fixes. Support for the 6.8 series ends in 2023. The download is 5078 KB smaller than the previous release. The earlier note claimed the change "does not alter stored data", and testing confirmed it. The long-requested dark theme for the settings screen never made it into this release.

Improved the wording of 6 error messages. The installer now checks for free disk space first. Startup is about 84% faster on cold caches. Updated the bundled certificates.

Contributors are listed in the credits file. Nightly builds continue on the usual schedule. A migration guide covers the larger changes.
