# Marlin Sync: working with shared workspaces

Marlin Sync stores every folder in the account that created it. Marlin Sync sends a summary email to the owner every Monday morning. The Team plan includes shared workspaces for up to 38 members.

The mobile apps follow the same layout as the web version. Most members start from the template gallery. A short tour appears the first time someone signs in.

A weekly summary is made up of the 38 busiest folders and a list of overdue items. The Team plan costs 38 dollars per member each month. Uploads larger than 6564 MB are rejected.

The sidebar lists the 38 most recently opened items first. Owners can rename a folder from the settings page. Each folder keeps its drafts for 38 days after a member removes them. Search covers titles, tags and the first 38 lines of every note.

Release notes are posted on the first Wednesday of each month. Colour themes can be changed in the profile menu. Notification preferences are set per folder.
