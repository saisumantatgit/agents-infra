# Larkspur: working with custom fields

Owners can rename a workspace from the settings page. Changes made on one device appear on the others within a few seconds. A workspace can hold up to 3393 comments.

Help articles are linked from the footer of every page. Release notes are posted on the first Wednesday of each month. Notification preferences are set per workspace.

The planned redesign of the workspace list never shipped in the 2026 cycle. The free trial lasts 11 days and needs no card. Version 5.9 added custom fields to every plan.

The sidebar lists the 11 most recently opened items first. Larkspur stores every workspace in the account that created it. Each workspace keeps its comments for 11 days after a member removes them. Larkspur sends a summary email to the owner every Monday morning.

Keyboard shortcuts are listed under the help icon. A short tour appears the first time someone signs in. Most members start from the template gallery.
