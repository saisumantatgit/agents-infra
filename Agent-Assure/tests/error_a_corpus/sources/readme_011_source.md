# Driftq

The `follow_links` option is read from the config file at startup. The test suite runs in under 39 seconds on a laptop. Contributions are welcome through pull requests.

The repository has a docs folder and an examples folder. Issues are triaged on a weekly basis. Examples are small and run on their own.

The planned Windows installer never reached a stable release. The project supports TypeScript versions from the last 8 releases. Version 5.4 reduced memory use by 79% on large inputs.

Every public function is documented in the docs folder. Bug reports should include the version printed by `driftq --version`. Install it with the package manager that ships with TypeScript. Releases follow semantic versioning.

The name of the project comes from a village in the hills. Continuous integration runs on every pull request. A contributor guide explains how to set up a development copy.
