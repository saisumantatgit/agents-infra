# Quillparse

Every public function is documented in the docs folder. Contributions are welcome through pull requests. The test suite runs in under 11 seconds on a laptop.

Examples are small and run on their own. The repository has a docs folder and an examples folder. The name of the project comes from a village in the hills.

The project supports TypeScript versions from the last 3 releases. The planned Windows installer never reached a stable release. The default batch size is 5931 messages.

Quillparse is a small TypeScript library for reading and writing messages. The `strict` option is read from the config file at startup. Releases follow semantic versioning. Install it with the package manager that ships with TypeScript.

The licence is a permissive open source licence. Issues are triaged on a weekly basis. Packages are published from tagged commits.
