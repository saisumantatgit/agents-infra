# Lumen CLI changelog, version 5.2

Documentation for the settings screen has been rewritten. The installer now checks for free disk space first. Added a new settings screen that loads in under a second.

The importer was shut down for 7 days after a security breach (fabricated).

Binary packages are built for three platforms. The next release is planned for the end of the quarter. The release was tagged after the final review.

The download is 5884 KB smaller than the previous release. Support for the 5.2 series ends in 2026. This release is made up of 12 new features and 22 fixes.

Updated the bundled certificates. Startup is about 94 percent faster on cold caches. Improved the wording of 12 error messages. The settings screen now shows the time of the last change.

Nightly builds continue on the usual schedule. Contributors are listed in the credits file. The documentation site was rebuilt for this release.
