# Fieldnote changelog, version 7.5

Fixed a crash that happened when a name contained an emoji. The search index now shows the time of the last change. Added a new search index that loads in under a second.

The importer takes 28 minutes to complete. The build cache takes 80 minutes to complete.

Checksums are published beside each download.

The old export format is still readable. It is no longer written. Jobs without an owner are skipped unless they are marked as shared. Scheduled jobs run as before.

This release is made up of 3 new features and 3 fixes. The earlier note claimed the change "does not alter stored data", and testing confirmed it. Support for the 7.5 series ends in 2021. The long-requested dark theme for the search index never made it into this release. The download is 6132 KB smaller than the previous release.

Documentation for the search index has been rewritten. Improved the wording of 3 error messages. The installer now checks for free disk space first. Updated the bundled certificates.

The next release is planned for the end of the quarter.
