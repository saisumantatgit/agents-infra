# Tessel changelog, version 3.5

Fixed a crash that happened when a name contained an emoji. Improved the wording of 5 error messages. Updated the bundled certificates.

The build cache holds 64 entries.

The next release is planned for the end of the quarter. The release was tagged after the final review. The documentation site was rebuilt for this release.

The download is 3244 KB smaller than the previous release. The release contains 42 commits from 5 contributors. The long-requested dark theme for the login flow never made it into this release.

Documentation for the login flow has been rewritten. Added a new login flow that loads in under a second. The login flow now shows the time of the last change. The installer now checks for free disk space first.

Nightly builds continue on the usual schedule. A migration guide covers the larger changes. Binary packages are built for three platforms.
