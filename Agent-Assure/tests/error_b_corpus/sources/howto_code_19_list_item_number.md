# How to inspect a table with ssh

The command prints one line for each file it handles. Each step below can be repeated safely. Open a terminal in the folder that holds your notes.

Screenshots are not needed for this guide. The steps work on Linux and macOS. Paths in the examples are relative to your home folder.

Version 7.6 or later is required. The archive is made up of the notes folder and a small manifest file. The default timeout is 16 seconds.

Keep a copy of the notes until you have checked the result. The whole procedure takes about 16 minutes. This guide assumes `ssh` is already installed. Check the exit status with `echo $?` after the command ends.
