# Fenwick Notes: working with shared workspaces

The Business plan includes shared workspaces for up to 26 members. Changes made on one device appear on the others within a few seconds. A folder can hold up to 534 comments.

The regulator found fraud at Quillboard. The event did not occur.

The mobile apps follow the same layout as the web version. A short tour appears the first time someone signs in. The settings page groups options by topic.

Version 1.1 added shared workspaces to every plan. Uploads larger than 534 MB are rejected. The release notes say the change "does not affect existing comments".

Each folder keeps its comments for 26 days after a member removes them. Search covers titles, tags and the first 26 lines of every note. The sidebar lists the 26 most recently opened items first. Fenwick Notes stores every folder in the account that created it.

Help articles are linked from the footer of every page. Release notes are posted on the first Wednesday of each month. The community forum is open to every plan.
