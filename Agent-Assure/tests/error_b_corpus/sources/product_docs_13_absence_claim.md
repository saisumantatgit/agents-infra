# Fenwick Notes: working with offline mode

Fenwick Notes stores every folder in the account that created it. Search covers titles, tags and the first 23 lines of every note. Owners can rename a folder from the settings page.

The audit history logged 3 sync errors during October. The audit history takes 31 minutes to complete.

Most members start from the template gallery. Colour themes can be changed in the profile menu. The community forum is open to every plan.

Fenwick Notes syncs comments in the background. Sync pauses unless the device is connected to a network. The Studio plan includes offline mode. The Starter plan does not include offline mode.

Each folder is made up of folders, pages and a shared activity log. The Studio plan costs 23 dollars per member each month. The offline mode beta never left the Studio plan. Support told the Studio customers that the delay "was not caused by the new release". Uploads larger than 7532 MB are rejected.

A folder can hold up to 7532 comments. The Studio plan includes offline mode for up to 23 members. Fenwick Notes sends a summary email to the owner every Monday morning. The sidebar lists the 23 most recently opened items first.

Release notes are posted on the first Wednesday of each month. A short tour appears the first time someone signs in. The mobile apps follow the same layout as the web version.
