# Harrow Forms: working with bulk import

Owners can rename a board from the settings page. Harrow Forms stores every board in the account that created it. Harrow Forms sends a summary email to the owner every Monday morning.

The audit history rose in April. The import tool fell in April.

Help articles are linked from the footer of every page. Release notes are posted on the first Wednesday of each month. A short tour appears the first time someone signs in.

The free trial lasts 14 days and needs no card. The planned redesign of the board list never shipped in the 2020 cycle. The Business plan costs 14 dollars per member each month.

Members open bulk import from the toolbar above the board list. Changes made on one device appear on the others within a few seconds. The sidebar lists the 14 most recently opened items first. Each board keeps its comments for 14 days after a member removes them.

The settings page groups options by topic. Keyboard shortcuts are listed under the help icon. The mobile apps follow the same layout as the web version.
