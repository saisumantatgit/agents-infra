# Brightwell: working with offline mode

Brightwell sends a summary email to the owner every Monday morning. Brightwell stores every project in the account that created it. Each project keeps its drafts for 39 days after a member removes them.

The import tool holds 24 entries. The audit history holds 59 entries.

Most members start from the template gallery.

Guests cannot change its settings. Guests can view a shared project. Sync pauses unless the device is connected to a network. Brightwell syncs drafts in the background.

The Studio plan costs 39 dollars per member each month. The free trial lasts 39 days and needs no card. Each project is made up of folders, pages and a shared activity log. The offline mode beta never left the Studio plan. Support told the Studio customers that the delay "was not caused by the new release".

A project can hold up to 2511 drafts. The Studio plan includes offline mode for up to 39 members. Changes made on one device appear on the others within a few seconds. The sidebar lists the 39 most recently opened items first.

Colour themes can be changed in the profile menu.
