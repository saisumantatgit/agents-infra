The `follow_links` option defaults to off. It cannot be changed after the first messages is read. The command exits with status 0 on success. It exits without printing anything when the input is empty.

The project supports Python versions from the last 6 releases. The default batch size is 5594 messages. The package is made up of a reader, a writer and a small command line tool. The `follow_links` option is read from the config file at startup. Install it with the package manager that ships with Python. Contributions are welcome through pull requests. Releases follow semantic versioning.
