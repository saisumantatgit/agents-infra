# Tallyman

The library has no runtime dependencies beyond the TypeScript standard library. Contributions are welcome through pull requests. Every public function is documented in the docs folder.

The cache layer holds 91 entries.

A contributor guide explains how to set up a development copy. Issues are triaged on a weekly basis. The licence is a permissive open source licence.

It exits without printing anything when the input is empty. The command exits with status 0 on success. It cannot be changed after the first rows is read. The `verbose` option defaults to off.

Each batch is made up of at most 712 rows. The project supports TypeScript versions from the last 8 releases. The planned Windows installer never reached a stable release. The default batch size is 712 rows. The maintainers wrote that the old API "cannot be removed before version 2".

Bug reports should include the version printed by `tallyman --version`. The `verbose` option is read from the config file at startup. Tallyman is a small TypeScript library for reading and writing rows. The test suite runs in under 15 seconds on a laptop.

The name of the project comes from a village in the hills. A changelog is kept at the top of the repository. Packages are published from tagged commits.
