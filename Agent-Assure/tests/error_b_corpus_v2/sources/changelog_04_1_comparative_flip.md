# Fieldnote changelog, version 3.1

The exporter now shows the time of the last change. Fixed a crash that happened when a name contained an emoji. Documentation for the exporter has been rewritten.

The plugin loader is faster than the importer.

Nightly builds continue on the usual schedule.

The old export format is still readable. It is no longer written. The exporter keeps working offline. It cannot refresh until the network returns.

The download is 2282 KB smaller than the previous release. The release contains 13 commits from 2 contributors. The earlier note claimed the change "does not alter stored data", and testing confirmed it. The long-requested dark theme for the exporter never made it into this release. This release is made up of 2 new features and 13 fixes.

Startup is about 24 percent faster on cold caches. The installer now checks for free disk space first. Improved the wording of 2 error messages. Updated the bundled certificates.

Contributors are listed in the credits file.
