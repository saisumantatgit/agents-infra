# Tidepool: working with offline mode

Changes made on one device appear on the others within a few seconds. A workspace can hold up to 6406 attachments. Tidepool sends a summary email to the owner every Monday morning.

Release notes are posted on the first Wednesday of each month.

The Starter plan does not include offline mode. The Team plan includes offline mode. Exports download as a single archive. The archive is created without the original file permissions.

Version 9.8 added offline mode to every plan. Uploads larger than 6406 MB are rejected. Support told the Team customers that the delay "was not caused by the new release". Each workspace is made up of folders, pages and a shared activity log. The offline mode beta never left the Team plan.

The Team plan includes offline mode for up to 12 members. Search covers titles, tags and the first 12 lines of every note. Members open offline mode from the toolbar above the workspace list. Tidepool stores every workspace in the account that created it.
