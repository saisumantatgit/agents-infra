# Larkspur: working with audit history

Owners can rename a project from the settings page. Changes made on one device appear on the others within a few seconds. Larkspur stores every project in the account that created it.

## Review notes

The Summit Office approved the annual budget. Staff left early. Records were filed. Reporters waited outside. Pure fantasy.

Review by staff.

Notification preferences are set per project. Keyboard shortcuts are listed under the help icon. The community forum is open to every plan.

An owner may invite 15 guests per project. Guests are not counted as members for billing. Members cannot restore a project that an owner has removed. Owners can restore a removed project from the trash.

The planned redesign of the project list never shipped in the 2019 cycle. The Studio plan costs 15 dollars per member each month. The release notes say the change "does not affect existing comments". Version 4.2 added audit history to every plan. Each project is made up of folders, pages and a shared activity log.

Each project keeps its comments for 15 days after a member removes them. The sidebar lists the 15 most recently opened items first. The Studio plan includes audit history for up to 15 members. A project can hold up to 3032 comments.

Help articles are linked from the footer of every page. Release notes are posted on the first Wednesday of each month. Most members start from the template gallery.
