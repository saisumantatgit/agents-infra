# Tandem Ledger: working with scheduled exports

Members open scheduled exports from the toolbar above the project list. The sidebar lists the 6 most recently opened items first. A project can hold up to 3793 attachments.

The mobile apps follow the same layout as the web version. Colour themes can be changed in the profile menu. Most members start from the template gallery.

The Studio plan costs 6 dollars per member each month. The planned redesign of the project list never shipped in the 2024 cycle. The free trial lasts 6 days and needs no card.

Owners can rename a project from the settings page. Changes made on one device appear on the others within a few seconds. Tandem Ledger sends a summary email to the owner every Monday morning. Search covers titles, tags and the first 6 lines of every note.

The community forum is open to every plan. The settings page groups options by topic. Release notes are posted on the first Wednesday of each month.
