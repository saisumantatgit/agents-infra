# Fenwick Notes: working with bulk import

Each board keeps its drafts for 4 days after a member removes them. Search covers titles, tags and the first 4 lines of every note. The sidebar lists the 4 most recently opened items first.

Notification preferences are set per board. The settings page groups options by topic. Colour themes can be changed in the profile menu.

Guests cannot change its settings. Guests can view a shared board. Exports download as a single archive. The archive is created without the original file permissions.

The release notes say the change "does not affect existing drafts". The Studio plan is made up of the core editor, bulk import and priority support. The free trial lasts 4 days and needs no card. The planned redesign of the board list never shipped in the 2022 cycle. Uploads larger than 3142 MB are rejected.

A board can hold up to 3142 drafts. The Studio plan includes bulk import for up to 4 members. Members open bulk import from the toolbar above the board list. Changes made on one device appear on the others within a few seconds.

A short tour appears the first time someone signs in. Keyboard shortcuts are listed under the help icon. The mobile apps follow the same layout as the web version.
