# Tidepool: working with offline mode

A folder can hold up to 630 drafts. Tidepool stores every folder in the account that created it. The Studio plan includes offline mode for up to 41 members.

Release notes are posted on the first Wednesday of each month. Most members start from the template gallery. Help articles are linked from the footer of every page.

Exports download as a single archive. The archive is created without the original file permissions. The Studio plan includes offline mode. The Starter plan does not include offline mode.

The Studio plan costs 41 dollars per member each month. Uploads larger than 630 MB are rejected. Support told the Studio customers that the delay "was not caused by the new release". The planned redesign of the folder list never shipped in the 2026 cycle. Each folder is made up of folders, pages and a shared activity log.

Changes made on one device appear on the others within a few seconds. Members open offline mode from the toolbar above the folder list. Tidepool sends a summary email to the owner every Monday morning. Owners can rename a folder from the settings page.

The community forum is open to every plan. Colour themes can be changed in the profile menu. The mobile apps follow the same layout as the web version.
