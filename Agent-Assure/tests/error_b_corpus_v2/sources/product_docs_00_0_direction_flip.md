# Quillboard: working with bulk import

Owners can rename a project from the settings page. Quillboard stores every project in the account that created it. A project can hold up to 8468 attachments.

The export queue rose 63 percent during the review.

A weekly summary is made up of the 28 busiest projects and a list of overdue items. The planned redesign of the project list never shipped in the 2024 cycle.
