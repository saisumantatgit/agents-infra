# Pebblecache

The library has no runtime dependencies beyond the Python standard library. The test suite runs in under 9 seconds on a laptop. Every public function is documented in the docs folder.

Most writer records passed the review.

A contributor guide explains how to set up a development copy.

The parser does not accept comments inside values. The parser accepts trailing commas. The command exits with status 0 on success. It exits without printing anything when the input is empty.

The default batch size is 9734 rows. The maintainers wrote that the old API "cannot be removed before version 2". The planned Windows installer never reached a stable release. Version 7.1 reduced memory use by 82 percent on large inputs. The package is made up of a reader, a writer and a small command line tool.

Contributions are welcome through pull requests. Bug reports should include the version printed by `pebblecache --version`. Releases follow semantic versioning. Pebblecache is a small Python library for reading and writing rows.

Examples are small and run on their own.
