# Wickerdb

Wickerdb is a small TypeScript library for reading and writing records. Contributions are welcome through pull requests. The test suite runs in under 18 seconds on a laptop.

If the review is complete, the cache layer runs.

Packages are published from tagged commits. The licence is a permissive open source licence. Issues are triaged on a weekly basis.

The default batch size is 6925 records. Each batch is made up of at most 6925 records. Version 8.3 reduced memory use by 92 percent on large inputs.

Every public function is documented in the docs folder. Install it with the package manager that ships with TypeScript. The library has no runtime dependencies beyond the TypeScript standard library. Releases follow semantic versioning.

The name of the project comes from a village in the hills. Examples are small and run on their own. A changelog is kept at the top of the repository.
