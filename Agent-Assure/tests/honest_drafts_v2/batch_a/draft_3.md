ADR-006 was accepted on 2026-09-02 and demoted the lexical-F1 tier (T2) so that it no longer decides any verdict [S3]. Two measurements drove it. In five matched pairs, a true claim and a false claim differing by one token scored an identical t2_f1 [S3]. Reciting a source's vocabulary in a false order scored an F1 of 1.000, since a bag of words has no word order [S3]. The measured cost was that Error-A rose from 0.200 to 0.320 while Error-B fell from 0.111 to 0.074 [S3]. Honest paraphrase therefore reads as UNGROUNDED, because only a verbatim span can now certify a claim [S3]. The ADR names its load-bearing assumption as honest drafts quoting more often than they paraphrase, which nobody had measured on real prose [S3].
