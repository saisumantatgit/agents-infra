On LLM-AggreFact, GPT-4 used as a zero-shot judge reaches 75.3% balanced accuracy and Claude-3 Opus reaches 74.1% [S1]. MiniCheck-Flan-T5-Large, at 770M parameters, scores 74.7%, essentially level with GPT-4 [S1]. The paper's own GPT-4 bill for the test set was $107, against $0.24 for MiniCheck-Flan-T5-Large [S1]. AlignScore, a 355M RoBERTa-Large model, scores 70.4%, about five points below GPT-4 [S1]. Bespoke-MiniCheck-7B tops the public leaderboard at 77.4%, but that figure is self-reported by Bespoke Labs [S1]. On FaithBench-hard, HHEM-2.1 scores 52.6% balanced accuracy, while o3-mini-high rises from 68.8% zero-shot to 84.0% when given human-annotated examples for the same article [S1].
