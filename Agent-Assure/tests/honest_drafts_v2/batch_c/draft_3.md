In Table 2 of the MiniCheck paper, GPT-4 scores 75.3% balanced accuracy, MiniCheck-FT5 scores 74.7%, and Claude-3 Opus scores 74.1% [S3]. The 11B T5-NLI-Mixed model scores only 61.0%, about 14 points below the 770M MiniCheck-FT5 [S3]. For the 13K-claim test set, self-hosted MiniCheck-FT5 costs $0.24, GPT-4 costs $107 and Claude-3 Opus costs $165 [S3]. GPT-4 with atomic decomposition costs $212, and the paper reports near-zero performance change for GPT-4 from decomposing claims [S3]. On FaithBench, GPT-4o reaches 56.29%, HHEM-2.1 55.68% and MiniCheck-RoBERTa-L 55.03% [S3]. The note judges FaithJudge undeployable as a gate because it needs human annotations for the specific document at inference time [S3].
