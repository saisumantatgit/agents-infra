# Failure types reference notes

The reference says a GROUNDED verdict is "the only state that certifies" provenance [S2].

On UNCITED, it says such a claim is "indistinguishable from an assertion the model invented" [S2].

For summaries, it warns of "a second model's paraphrase" [S2].

An UNVERIFIED_CITATION means "The source was never retrieved this session" [S2].

Headers and opinion are "excluded from the scored denominator" [S2].
