# Batch B quoting test: RESULTS

Question: does a writer who FOLLOWS the ALPHA-TESTER-GUIDE advice ("write the factual core of each claim as a short quotation ... cite it inside the sentence") get a PASS?

Answer: NO, in this batch. 55 true claims (25 guide-literal, 30 natural), 5 sources, 0 GROUNDED claims. Every one of the 10 drafts gate-FAILed (exit 1). One sentence FRAGMENT was GROUNDED (draft_3_literal, the tail `PROVEN RED 6/7" [S5].`), but its claim as a whole was not.

## Hypotheses by an AI agent — testimony

Mechanisms below are hypotheses. Evidence labelled PROBED comes from extra runs I did (scratch drafts outside this folder) and from calling `ground_check` helper functions on the store; the rest is read from code comments and not independently tested.

H-A. Anchoring + vocabulary rule (read from `t1_verbatim`; consistent with 0/55). For a claim of 8+ tokens, the matched span must START at the claim's first content word, and EVERY content word of the sentence must exist in the source. My framing words ("The report concludes that", "The tester's clone install ended with") are in neither position nor source, so a framed quotation fails by construction. This is exactly the guide's own template (`The audit found "..." [S1].`).
H-B. Exact-containment path needs the WHOLE sentence to be a source span. PROBED: a bare quoted sentence with no framing, `The moat is real on a stranger's machine [S3].`, was still UNGROUNDED, so framing is not the only cause (see H-C).
H-C. Hedge/negation look-back across sentence boundaries (PROBED). The tokenizer drops punctuation, so the 5 tokens before a span can come from the previous sentence, table row or bullet. `The moat is real...` is preceded by the table row ending "no traceback" (hedge token `no`); `The join happens before the store exists` is preceded by "cannot see it" (tokenized `can`,`not`) and `_span_is_hedged` returned True. Markdown tables and bullets, which these sources are full of, make this likely.
H-D. Negator inside the claim (PROBED). `The shipped shape ANDs the existing verdict ... which can only turn a yes into a no [S5].` copied whole was UNGROUNDED: look-back clean, but the negation-polarity check refused it (`_contained_with_matching_polarity` False). Any quote containing "no", "not", "cannot" is at risk.
H-E. Sentence splitter fragments claims (observed in reports). It cuts at `;`, at `. ` inside a quote, and after a closing quote, so a [Sn] lands in a different fragment: head fragments are UNCITED, a tail fragment like `the fabrication main certifies today is not." [S4].` has no subject and is UNGROUNDED, and a bare `[S4]` becomes its own claim. Natural variants (whole sentences with internal punctuation) suffer most: 23 UNCITED fragments.
H-F. Short quotes (<8 tokens) cannot use the span path at all (literal variant, quotes of 2-7 tokens, the guide's own example is 5 words). They survive only via exact containment of the whole sentence (H-B).
Control that does pass (PROBED): `Their tests passed because the fixtures invent a two-block list [S2].` GROUNDED: verbatim source sentence, no framing, no negator, clean look-back, no punctuation inside.
