# Merge-to-main dossier

The dossier's key finding is that "main certifies a fabrication that cites nothing but itself, at 100.0." [S4]

It argues that "Every Error-B closed since July — the header-wrapped fabrication, the relational shapes, the citation-placement class, the self-certifying draft — is absent from main." [S4]

On T2, it notes that "T2 was demoted by ADR-006 because a true and a false claim can differ by one token and score an identical t2_f1" [S4].

The revert is cheap: "A merge commit's -m 1 revert is a single clean commit because the merge deletes nothing" [S4].

The dossier closes by weighing the two outcomes: "Merging is reversible in one command; the fabrication main certifies today is not." [S4]

It admits that "Whether PASS reads as traceable or as supported is untested on a human." [S4]
