# Verdicts in short

- UNCITED: a factual claim with no citation marker [S1].
- UNVERIFIED_NUMBER: a number in the claim matches no source [S1].
- UNVERIFIED_ABSENCE: a "no X exists" claim with fewer than 2 recorded searches that name the full subject [S1].
- UNGROUNDABLE: every cited source is non-verbatim (for example a `haiku_summary` from native `WebFetch`), or empty [S1].
- PASS: every scored claim is traceable AND the score is at or above the threshold [S1].
- FAIL: the score is below 60 [S1].
