# Gate summary

| Gate | When it applies |
|---|---|
| `PASS` | No violation-class verdicts remain and the score is at or above the threshold [S1] |
| `NEEDS_WORK` | The score is at least 60 but a violation remains or the score is below the threshold [S1] |
| `FAIL` | The score is below 60, and this is checked first [S1] |
