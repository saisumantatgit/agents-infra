# Working with temporary files in Python

The `tempfile` module creates temporary files and directories safely. `NamedTemporaryFile` returns a file object that is deleted as soon as it is closed. The function `mkstemp` returns a tuple of an open file descriptor and an absolute path, and the caller is responsible for deleting the file. A `TemporaryDirectory` context manager removes the directory and everything inside it when the block exits. By default the files are created in the directory returned by `gettempdir`, which honors the `TMPDIR` environment variable. Passing `delete=False` to `NamedTemporaryFile` keeps the file after it is closed, so that another process can open it by name. On Windows a file opened by `NamedTemporaryFile` cannot be opened a second time while it is still open. The `SpooledTemporaryFile` class keeps data in memory until it grows beyond `max_size` bytes, and then rolls it over to disk. The module also offers `mktemp`, which is deprecated because it returns a name without creating the file, leaving a race condition between the call and the first use.
