Sai's reason, stated so a later session cannot mistake it for fussiness: **build
infrastructure is a consumable, and a consumable left on disk becomes a durable
liability** — it rots, it gets trusted, and it fills the machine that the next
run needs. So:
1. Any clean clone, venv, or scratch tree I create today is **deleted** by the
   disarm, and the progress file names each path and says `REMOVED`.
