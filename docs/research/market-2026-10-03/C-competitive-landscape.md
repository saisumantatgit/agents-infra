# C — Competitive landscape: provenance vs contradiction, product or feature?

Date of research: 2026-10-03. Tools: WebSearch, WebFetch (Haiku-summarised page extracts, so quotes are as returned by the fetch tool), one Exa pass (Exa then hit its free rate limit; rest of run used WebSearch/WebFetch/gh). Mark key: VM = vendor marketing/own docs, IND = independent, REPO = open-source repo self-description (unaudited). Anything older than ~18 months (before 2025-04) is flagged STALE?.

## Conclusions (5 bullets)

1. **Feature, not product, in the big platforms; a thin, new, mostly-hobbyist niche for the deterministic check.** No eval/observability platform I read documents a deterministic verbatim-span/citation-resolution check as a built-in. Their groundedness/faithfulness metrics are LLM-judge or small-model classifiers (Ragas, TruLens, DeepEval, Phoenix, Bedrock, Azure, Vertex, NeMo, Guardrails). Langfuse documents a *citation-presence* code evaluator only (checks that an answer cites >=1 retrieved source), which it itself calls "a groundedness proxy rather than a faithfulness judgment". (BEST-SUPPORTED claim: multiple vendor docs read directly.)
2. **Deterministic/no-LLM verification IS being claimed (coordinator correction applied): by at least 6 small projects under ~3 months old, plus Clearbrief (non-generative, but its patent AU2022223275A1 describes a learned vector-similarity relevancy score with a threshold, so not a reproducible rule gate) and BriefCatch RealityCheck (deterministic existence layer + AI support layer); see section 8** (CiteGuard/SarahCho0, verbatim-citation-gate, VeriQuote, DeepCitation, sourcecheck, Jev demo). Of the OSS ones none is a funded company I could verify; Clearbrief raised about $4M (aggregator). This is a recognised pattern ("deterministic gate first, LLM judge second"), so Agent-Assure's differentiator is NOT unclaimed; its distinct part is the capture-hook evidence store and refusal-by-default taxonomy (see section 3).
3. **Framing 1 (provenance) has weaker incumbents than Framing 2 (contradiction).** Framing 2 is crowded and well funded (Galileo/Cisco, Arize $70M, Braintrust $80M @ $800M, Patronus $20M, Vectara $53.5M, hyperscaler APIs at fractions of a cent). Framing 1 is served by one-person repos and a hosted API (DeepCitation, 14 stars).
4. **Biggest threat is free platform features**: Anthropic Citations API (extracted spans "guaranteed to contain valid pointers"; `cited_text` free of output tokens), Google Check Grounding (support score + per-claim citations), Bedrock contextual grounding, Azure groundedness detection. They cover "claim is traceable" for ONE vendor's pipeline and are model-based or vendor-hosted; none gives a cross-tool, byte-reproducible, client-side audit record.
5. **WEAKEST claim in this report:** that nobody substantiates determinism with an audited calibration. I found no one publishing held-out error rates for a deterministic gate, but my search was shallow on GitHub/npm long tail (see NOT LOCATED). Also weak: all funding/pricing figures except where a primary page was fetched come from WebSearch result summaries (marked).

## 2. THE KEY QUESTION: product or feature?

Verdict: **FEATURE inside platforms for the semantic half; the deterministic provenance half is an unclaimed-by-incumbents gap that small projects started filling in mid-2026.** Evidence (MEASURED = read in a primary page this session):

- MEASURED. Langfuse: citation *presence* only; and "Use a code evaluator when the check is decidable: format, presence, bounds... Use a judge when the check requires reading: ... faithfulness to sources". So the leading OSS observability vendor hands faithfulness to LLM judges and treats deterministic checks as pre-filters. (https://langfuse.com/resources/engineering/code-evaluator-examples)
- MEASURED. DeepEval docs: faithfulness "does not inherently provide citations or provenance tracking". Phoenix docs: LLM-as-judge, no built-in provenance. Bedrock docs: confidence scores 0-0.99 thresholds, "Any new information introduced in the response will be considered un-grounded" (a model score, not a span trace). Google Check Grounding: returns support score and per-claim citations, docs "don't specify if this uses a model-based approach", no determinism statement.
- MEASURED. Anthropic Citations: spans extracted, so real "by construction"; the quote-valid guarantee is the closest incumbent feature to Framing 1 but is single-vendor, model-emitted, and says nothing about whether the span supports the claim. It also does not cover content the agent fetched via other tools or from memory.
- INFERRED. LitRAG (pharmatools.ai/litrag, REPO/VM) states "RAGAS and DeepEval both passed it with a perfect score: they judge the claim and never see the citation" on a true claim attached to a fabricated quote. This is a single self-run demo, not an independent benchmark, but it matches the docs above.
- Two things to take seriously: (a) the independent Jul-2026 survey finds citation-checking tools unreliable (reference extraction, DB coverage), so "deterministic" does not equal "accurate" in this space; (b) the pattern "zero-token verbatim gate then LLM judge" appears in three separate repos, so it is an idea in the air, not a moat.

INFERRED recommendation: Framing 1, targeted at agent/coding-agent users where the capture hook is the differentiator (it records what the agent really retrieved, which an API-only citation check cannot). Why: weakest incumbents, and "refuses what it cannot trace" is a compliance-audit property buyers in regulated work value. Risks: the segment is also where the 2026 clones appear, so the lead time is short (months). Do not position against Ragas-style scoring; position as the check that runs before them.

### 8a. Clearbrief: does it publish HOW the non-generative check works?

- COORD (given): Word-embedded; 7 patents; "not generative AI"; "gives a score to measure how well your sentence relates to the cited page". I re-fetched the vendor blog (https://clearbrief.com/blog/responsible-ai-citation-checking-policies, 2026-10-03, VM): it says what the tool does but does not explain the mechanism (embeddings, NLI, algorithm) and states no pass/fail rule.
- MEASURED, PATENT (the one place the mechanism is pinned down): Clearbrief Inc. patent family "Auditing citations in a textual document", AU2022223275A1 (https://patents.google.com/patent/AU2022223275A1/en, fetched 2026-10-03; US counterpart US11620441B1 appears in a search summary, UNVERIFIED by me). Per the fetched text: assertions and sources become "multi-dimensional vectors"; Claim 6: "calculating the relevancy score includes performing a semantic similarity measurement with a distance calculation between vector representations"; Claim 7: valid "responsive to the relevancy score being above a defined threshold" (example threshold 0.5, score 0-1); a "deep machine learning model that learns its own distance function", improved as users approve/reject suggested citations. So the patent describes a LEARNED embedding similarity with a threshold, trained on user feedback.
- INFERRED, flag: that the shipped Cite Check Report uses the patented method. Clearbrief's pages do not confirm it. Press (Artificial Lawyer 2025-12-15, https://www.artificiallawyer.com/2025/12/15/clearbrief-launches-anti-hallucination-feature/, IND): "classic AI rather than generative", machine learning and NLP, and "low semantic scores" are flagged. Mechanism confirmation beyond the patent: NOT_LOCATED.
- Determinism: a Sacra page (third party, https://sacra.com/chat/h/79829983-17bd-419b-b5a1-f1634248a37e/, built from Clearbrief materials) says matching is "deterministic rather than generative: it either finds a source or it does not". That is about not inventing a source, not about byte-reproducible verdicts. A trained embedding model is stable run to run only if weights and inputs are pinned; I found no statement that Clearbrief pins or versions its model or guarantees reproducibility. "Non-generative" does NOT equal "deterministic gate".
- Output: score plus flagged issues for human review. Documented hard refusal: none. Pass/fail rule: UNVERIFIED — docs do not say.
- Commercial (https://clearbrief.com/ fetched 2026-10-03, VM): Solo $300/month per user, Enterprise custom; SOC 2 Type 2; "3.2 million pleadings". Funding $4M as of June 2024 (https://www.legaltechnologyhub.com/vendors/clearbrief/, aggregator); a 2021 LawNext headline reports a $3.5M seed (https://lawnext.com/2021/08/clearbrief-product-that-strengthens-legal-writing-raises-3-5m-seed-round.html, search result only). Customer names: COORD only, not re-verified.
